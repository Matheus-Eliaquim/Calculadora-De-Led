# 💡 Calculadora de Led 💡

Este projeto visa a aplicação dos meus conhecimentos em **REACT**, servindo como prática para consolidar o aprendizado, também é utilizada como ferramenta pessoal de trabalho, facilitando calculos diarios que preciso fazer.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** → Estrutura base da página  
- **CSS3** → Estilização de componentes e responsividade  
- **REACT/JavaScript** → Estrutura principal do projeto, componentização
- **Material UI** → Biblioteca de componentes para React

---

## 📌 Observações

- **Compatibilidade**: O projeto possui suporte para dispositivos móveis, notebooks e computadores.   
- **Estética**: O projeto ainda vai passar por melhorias visuais, o foco por enquanto ainda é o desenvolvimento do codigo

---

## 📝 Sobre o Projeto

Este projeto é um laboratório pessoal, onde testo meus conhecimentos em React. À medida que adquiro novas habilidades e passo a conhecer a tecnologia de forma mais aprofundada, pretendo implementar mais funções para tornar a calculadora mais dinâmica e precisa.

Quanto ao uso do projeto no meu dia a dia de trabalho, na versão atual ele já facilita bastante, realizando cálculos e contagens que antes eu precisava fazer manualmente ou em planilhas. No entanto, ainda não atende 100% das minhas necessidades, pois algumas etapas continuam sendo feitas manualmente. Isso ocorre porque ainda não possuo conhecimento suficiente para implementar tudo o que é necessário para automatizar completamente o meu processo de trabalho.

---

## 🚀 Próximos Passos


- Exclua valores que foram adicionados e que essa exclusão seja contabilizada no relatório.
- Adicionar uma nova calculadora para perfis especiais, alguns fabricantes fazem perfis com medidas de 0.50m até 3.00m e isso possibilita calcular barras de perfil de forma mais efetiva e diminuir a quantidade de sobras. Essa parte precisa ser uma calculadora especial, pois nem todo fabricante faz dessa forma, a calculadora padrão de perfil atende ao que o mercado em sua maioria ja faz, mas a especifica vem para atender a demanda de um fabricante que tras novas possibilidades.
